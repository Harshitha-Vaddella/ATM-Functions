# ATM Functions

## Project Overview
The ATM Functions project is a Python-based ATM Simulation System developed using Object-Oriented Programming concepts. It allows users to perform basic banking transactions through a simple menu-driven interface.

## Features
- Deposit money into an account
- Withdraw money from an account
- Check current account balance
- Validate deposit and withdrawal amounts
- Prevent withdrawals exceeding available balance
- Interactive ATM menu

## Technologies Used
- Python

## OOP Concepts Used
- Classes and Objects
- Constructors (`__init__`)
- Encapsulation
- Inheritance
- Method Overriding
- Polymorphism

## How to Run
1. Install Python.
2. Clone or download this repository.
3. Open the project in VS Code.
4. Run the following command:

```bash
python oops_atm.py
```
